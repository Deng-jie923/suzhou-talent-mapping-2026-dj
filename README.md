# 苏州硬科技岗位Mapping练习（数字IC验证 + 大模型应用，公开数据版）

这个仓库是我练习硬科技猎头人才mapping的材料。目标：只用公开渠道的招聘信息，把苏州的数字IC验证/设计岗和大模型应用算法岗样本整理出来，做薪资分层、技能词归纳和公司类型对比，为猎头实习面试攒一份能说清楚来龙去脉的东西。岗位信息均发布于2026年9—10月（薪酬数据更新时间单独备注），链接见文末。

- 数字IC验证/设计（主方向）：芯弦半导体、盛科通信、晶瞻半导体、景昱医疗等苏州工业园区岗位。校招验证岗公开月薪10k—15k（盛科通信，郑州大学就业网）到40万元/年（芯弦半导体）；社招设计岗20-40k·13薪（晶瞻半导体，3年以上）、50—70万元/年（景昱医疗，5年以上）。JD高频词：Verilog、SystemVerilog、UVM、SoC系统级验证、APB/AHB/AXI、TCL/Perl/Shell、VCS/Spyglass/DC/PT。
- 大模型应用（对照方向）：苏州国芯、领世（苏州）机器人、亿咖通等。入门岗15-25k·14薪（亿咖通，本科可投），1-3年岗20-40k·13薪（苏州国芯，硕士），专家岗60-90k·15薪（领世机器人，硕士，端侧推理）。JD高频词：PyTorch、Transformer、vLLM/TensorRT、量化推理。
- 薪酬参照：IC验证工程师平均招聘月薪26,558元（智联招聘《2026新质生产力人才发展报告》，2026年春节后一个月，深圳政府在线转载）；苏州数字IC设计岗月薪中位数22,500元、52.4%落在15-30k（谈职，2026-10-14更新）；AI算法工程师（大模型）1.5-3万×14薪（全职网转载猎聘）。
- 目标岗位（立跃，半导体方向猎头实习生）：12万元/年，苏州工业园区，岗位职责含电话沟通与信息收集、人才储备库、行业人才趋势、客户拜访；通用猎头实习生岗位的专业要求里明确有汉语言文学。

分析方法：按“验证/设计”“大模型应用”分开看关键词出现情况，再按薪资—经验分组，最后按公司类型（科创板上市、纳斯达克上市、本土Fabless、合资、初创）比较JD差异。所有数字照页面原文记录，不做合并或估算。

局限声明：样本量有限，仅覆盖苏州部分公开岗位，不构成招聘建议，不含任何非公开候选人数据。
